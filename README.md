# محمد يحيى للقرآن 📖

تطبيق أندرويد مجاني بالكامل (كود مفتوح) لقراءة القرآن الكريم والاستماع لكل آية على حدة.

## المميزات
- كل سور القرآن الـ114 كاملة (نص مصحف عثماني مضمّن داخل التطبيق — يعمل بدون نت).
- داخل كل سورة: زر **اختر القارئ** (ياسر الدوسري، العفاسي، عبدالباسط، السديس...).
- اضغط على أي آية → يُقرأ نص **الآية كاملة** بصوت القارئ المختار.
- زر **تشغيل السورة كاملة** يقرأ الآيات متتالية مع تظليل الآية الحالية.
- زر **تحميل السورة**: يحفظ صوت السورة على الجهاز مرة واحدة، وبعدها تعمل **بدون إنترنت**.

## ⚠️ ملاحظة مهمة عن الشيخ الشعراوي
الشيخ محمد متولي الشعراوي رحمه الله **ليس له تسجيل تلاوة كاملة للمصحف** آية بآية (المتوفر له هو خواطر التفسير فقط).
لذلك خيار "الشعراوي" في القائمة حالياً يُشغّل صوت العفاسي كبديل مؤقت. إذا وجدت مصدراً صوتياً له آية-بآية، غيّر قيمة `folder` في ملف `Data.kt`.

## كيف تبني ملف APK مجاناً (بدون تثبيت أي شيء)
1. أنشئ حساباً مجانياً على GitHub وارفع هذا المجلد كمستودع (Repository).
2. اذهب إلى تبويب **Actions** → سيشتغل "Build APK" تلقائياً.
3. بعد انتهائه، حمّل ملف `MohammedYahyaQuran-apk` من Artifacts → فيه `app-debug.apk`.
4. انسخ الملف لجوالك وثبّته (فعّل "مصادر غير معروفة").

### أو عبر Android Studio
افتح المجلد في Android Studio → Build → Build APK(s).

## مصدر الصوت
ملفات mp3 لكل آية من موقع everyayah.com (مجاني). التحميل يحتاج نت مرة واحدة فقط لكل سورة لكل قارئ.
